# 同桌：共享办公桌改版

## 方法与方向

使用 design-taste-frontend 上游的应用界面流程（app-screens），临时安装在仓库外，不改动用户原有 skill。
抽取结果：Achromatic ledger；seed 930283962；shell No sidebar；未重抽。
选择理由：这是长时间使用的文件工作台，而不是营销页。全宽资料列表优先，减少侧栏与说明性装饰。

## 数据与工作清单

- 对象：文件、图片、文字、文件夹，均来自已有 Go API；不编造业务数字。
- 名称、共享者、大小、创建时间为主要字段；大小以 B/KB/MB/GB 显示。
- 主问题：我现在要找的资料在哪里，怎样最快交给同事？
- 主动作：上传；次动作：分享文字。文档点开即读，图片点开预览。
- 多人在线与活动由 SSE 和 overview 提供，人数不充当传输性能指标。
- 个人收藏、最近共享、回收站是独立列表视图，保留现有逻辑。
- 用户已有图片作为缩略图，不引入装饰照片或虚构客户资料。
- 上传真实进度、单项/批量重试、原始文件保留策略全部保留。
- 帐号、会话和后端权限模型不变，不迁移框架、不迁移数据。
- 移动端需有可读的资料行，不把桌面表格横向推到屏外。

## 产品面孔与独有结构

面孔：蓝灰纸面 #f2f4f7，白色资料面；黑色双桌标记与“同桌”名称；Geist 本地字体。
独有结构：把文件、截图、文字视为同一张办公桌的三种资料，而非三个页面。拖拽入口与粘贴快捷键组成一条传递资料的操作带，紧接实际文件夹与列表。

## 布局算式

根据实际大屏截图反馈，画布改为流式宽度，最大 1680px，桌面常规外边距 32px。
1920px：120 + 主资料区 1368 + 间距 24 + 信息栏 288 + 120 = 1920。
1440px：32 + 主资料区 1064 + 间距 24 + 信息栏 288 + 32 = 1440。
顶栏、标题行、资料表和页脚共用外边线。以上算式未扣系统滚动条；中尺寸各 24px，手机各 16px。
移动端导航收起，桌面列信息合并为两行资料行；保留名称、类型、共享者、时间、大小与操作。

## 审视旧版

源代码 app lint：0 FAIL / 14 WARN，主要是 eyebrow、休息状态阴影、monospace 标签、弹窗背景模糊。
最明显的问题：文字过小、灰度太淡；侧栏和说明栏占用资料宽度；上传区和文件夹区把真正的文件列表推后。
浏览器尺寸和截图验收使用宿主 CUA。独立 inspect.mjs 会启动外部 CDP，故不使用该浏览器驱动；不将 CUA 检查冒称完整 inspect.mjs 检查。


## 看图与修正（两轮）

第一轮：去除旧版侧栏、渐变、背景模糊和装饰标签；将上传、文件夹、真实资料放入同一条工作流。发现手机横向溢出、元数据挤压以及浅色分隔文字对比不足。
第二轮：手机隐藏冗余桌面列，改用两行资料摘要；移除重复的上传提示区；将次要行操作放入支持键盘的菜单，补足图标按钮名称；修正分隔文字对比。没有重抽方向。

### 七项审视

1. 工作台回答“资料在哪里、怎样交给同事”；标题后就是上传主动作、文件夹和资料列表。预览回答“里面是什么”；设置回答“我用什么账号、怎样管理成员”。没有抢占主内容的营销数字。
2. 顶栏、标题和内容共用流式画布外边线；右栏从上传操作带齐头，不强制与资料列表等高；没有假空行填充。
3. 黑白灰构成界面，绿色只表示真实在线，红色只表示错误，存储条为单一数据色；双桌标记、字体和纸面在首屏可见。
4. 右栏文件/图片/文字计数来自 activeItems，是包含所有文件夹的全空间统计，旁边明确标注范围；列表标签来自 scope，随当前目录或视图变化。全部还包含文件夹，所以三类计数之和不冒称全部数量。存储百分比来自 used / quota，空空间从 0 开始。大小右对齐并用 tabular-nums。
5. 无文件计数展示 0，文件夹大小展示破折号；不在导航堆积无意义角标。不制造下载量或活跃率。
6. 本项目没有图表图例；状态圆点均伴随文字。长名称单行省略但保留完整 title，详情显示完整名称。
7. 390px 导航折叠，资料行仍保留名称、类型、发布者、时间、大小和下载/复制；更多菜单继续提供收藏、重命名和软删除。

## 验证记录

- 宿主 CUA 实际检查 1440×900、768×1024、390×844，三种宽度页面横向溢出均为 0px；可见叶文本最小 11px；以实色祖先背景计算的正文对比检查没有低于 4.5 的项。这是针对本页面的检查，不替代完整可访问性审计。
- 三种尺寸左右内容边距对称；手机由旧版 84px 横向溢出修为 0px。手机首条资料在 y=502px，首屏可读到多条资料。
- CUA 验证：手机导航、收藏空状态、搜索、列表/网格、文字点开即读、更多操作→重命名、个人设置、退出及重新登录。
- 源码 app lint：0 FAIL / 4 WARN。四处阴影仅服务真实浮层：传输队列、弹窗、消息通知、行操作菜单；静态资料卡片没有阴影。未运行独立 CDP inspect.mjs。
- 前端 27 项回归测试通过，覆盖原字节上传、失败重试、并发控制、粘贴命名与文档预览；生产构建通过；Go race 测试及 go vet 通过。
- 本地测试用的 1px 图片、周会便签只在开发数据库中，不随版本发布；线上直接使用现有团队资料，无待替换的模拟数字或演示成员。

线上复核发现根目录标签与全空间统计的口径容易混淆，补充“全空间统计，包含所有文件夹”说明，并在在线人数旁写明“人在线”。这是第二轮对真实数据的校正。


## 第三轮：根据用户的大屏截图修正比例

### 诊断

用户在 1920px 大屏、根目录只有四条资料时，1200px 的窄居中列导致左右大幅留空；资料列表结束后，八条活动仍把整块右栏拉成长白条。首次验证偏重完整数据和手机溢出，遗漏了这类“少资料、多动态”的真实状态。

### 三项修正

1. 宽度：画布从最大 1200px 调整为最大 1680px 的流式工作区，主资料区优先，信息栏固定 288px；中小尺寸仍保留原有单列策略。
2. 主次：右栏拆成空间概览、团队协作、最近动态三个独立面板；动态视区最高 210px，鼠标/触控/键盘可独立滚动，仍展示接口返回的全部活动，长名称有完整悬浮提示。移除右栏重复说明和宣传式尾部。
3. 密度：统一主内容区 18px 间距、缩小重复的垂直留白；桌面资料行从 76px 调为 64px，名称提高到 14px、元数据 13px。手机保留 88px 触控资料行。

### 验证

使用独立临时数据库复现：4 条有效资料、8 条真实测试活动；与生产数据分离，测试文件不会发布。

- 1920×953：主区宽 1368px、信息栏宽 288px；整个页面高 953px，没有被活动撑长。动态可视高 210px、内部内容高 604px，可独立滚动。
- 1440×900：主区宽 1064px；首条资料 y≈442px，四条资料完整可见；页面高 900px，无多余整页滚动。两侧栏内容结束位置相差约 44px，而非长条失衡。
- 768×1024 与 390×844：横向溢出均为 0px；中尺寸概览与成员自然高度，不强行拉成等高卡片；手机首条资料 y≈395px。
- 浏览器复核正文预览、网格切换、收藏空状态、窄屏更多菜单；回归测试与生产构建通过。
- 延续 Achromatic ledger / seed 930283962，不重抽风格。源码样式检查仍为 0 FAIL / 4 WARN，四处均为既有的真实浮层阴影。


## 2026-10-23：更新排序与稳定文本编辑

- 默认排序、更新时间列和最近 7 天视图统一使用 updated（兼容缺失数据时回退 created）；创建时间保留。后端列表同步排序，避免只对返回的旧数据在浏览器里重排。
- 预览与编辑共用 text-dialog；固定自适应窗口和可滚动正文，标题和元数据位置一致，编辑后自动聚焦正文，保存后仍可阅读全文。纯文字空正文可保存；错误时保留编辑内容。
- 独立本地测试便签：先创建旧便签，再创建新便签，通过 UI 编辑旧便签后确认排序升到第一，正文预览显示保存后的新内容。
- 1440×900 实测：读/写窗口均 850×720；正文均 794×508.5，位置一致。390×844 实测：窗口均 351×720，正文均 315×514，位置一致；没有切换时缩小。
- 31 项前端测试通过；Go race、vet 通过，新增老数据库增量迁移/重复启动、编辑置顶/保持创建时间、收藏不改更新时间、上传初始时间测试。


## 2026-10-23：修正保存收尾与交互过渡

用户指出保存后仍停在预览、还要再手动关闭。按新的明确交互要求撤回上一轮“保存后返回预览”的决定：成功后同时清空编辑与预览状态，直接回到更新后的资料列表；接口失败仍保留原文、编辑状态和错误提示，支持再次保存。

将纯文字读写区域拆为 TextNotePanel。预览与编辑共享原窗口、标题、元数据与正文位置，90ms 淡出 + 90ms 淡入完成模式切换；不重新挂载整个窗口。长文滚动位置在切换前后保留，进入编辑后焦点落在正文，取消后回到原预览与编辑按钮。关闭键始终关闭整个弹窗；成功退出后恢复到原列表触发项。

弹窗使用 180ms 打开、140ms 关闭过渡；菜单与消息提示使用 120ms 过渡。只对 transform/opacity 做运动，不动画宽高。系统设置 prefers-reduced-motion 时停用这些运动，不引入动画库。离场浮层和离场模式禁用输入，快速重新打开会恢复输入状态。

本地验证：通过代理让首次编辑保存返回 503，正文保持、错误显示；第二次保存成功，dialog 数量为 0，列表正文已刷新且编辑文件在第一位。桌面与 390px 手机都确认成功后自动关闭；读写正文尺寸仍一致。55 行长文本阅读滚动 1002px，进入编辑及取消后都保留 1002px。手机窗口保持 351×720，正文保持 315×514；桌面窗口保持 850×720，正文保持 794×508.5。正常界面控制台无错误。回归测试、构建、Go race/vet 通过。
