## PRODUCT-001：企业文件协作的目标边界

- 状态：已确认，2026-10-28；适用于本次 UI 与后端开发方案。
- 决定：公司内部团队为主、不开放注册；个人空间 + 团队空间；桌面优先，手机支持浏览、上传、下载和分享。
- 来源：用户对三个需求问题的明确批注，分别为“不开放注册 公司内部团队为主”“个人加团队”“桌面优先，手机支持浏览、上传、下载和分享”。
- 理由：内部账号管理、私有/团队资料隔离和桌面效率为主要体验目标。
- 影响：据此提出增量 [开发方案](../plan/shared-files-development-plan.md) 和 [HTML 原型](../preview/office-share.html)；角色细节、外部分享、配额与文件大小等仍是方案建议，未将其登记为已确认决定。
- 边界：本次请求授权制作方案与原型，不包含后端上线、生产迁移或部署授权。


## PRODUCT-002：动态置顶、公开与指定成员分享

- 状态：已确认，2026-10-28；来源为用户本轮在交互预览中的新增要求。
- 决定：置顶目录不限于三个预置项，支持修改；分享支持任何人持链接访问与指定成员访问，并提供设置；文件格式保持一致。
- 实施解释：置顶采用每用户每空间的快捷入口，支持添加/取消/排序和资源重命名；链接设置包含访问范围、接收人、有效期、下载开关和撤销；原格式下载与扩展名保护一并纳入。
- 替代关系：替代开发方案 v1.0 的 A04“外部匿名分享不纳入首期”建议；不改变 PRODUCT-001 的内部账号制与不开放注册。匿名分享访客只访问链接范围，不进入工作台。
- UI 批注：修复搜索快捷键标签换行，移除侧栏提示及底部原型条；账号选择改为与布局一致的自定义菜单，而非系统原生下拉框。
- 当时边界：本决定最初落地于 HTML 原型与开发方案；后续本地实施授权与 UI 定稿见 PRODUCT-003。详见 [开发方案](../plan/shared-files-development-plan.md#12-分享账号与审计)。
