# 交互原型验证方法

范围：独立 HTML 与其浏览器内模型；不是现有 Vue 应用或后端的验收。
当前执行结果唯一记录在 [NOW：原型验证](../context/NOW.md#原型验证)，此处只维护复现方法。

## 打开

- 双击 [office-share.html](../preview/office-share.html) 可浏览核心界面。
- 推荐使用 localhost 体验系统剪贴板；在项目根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs
```

访问 [本地交互预览](http://127.0.0.1:8765/preview/office-share.html)。这只启动文档预览，不启动 Go 服务，也不接触业务数据库。结束预览时在启动终端按 Ctrl+C。

默认全部变化只留当前页面内存；刷新恢复初始数据。请使用测试文件，文件内容不发送网络。

## 自动化模型检查

在项目根目录执行，无需安装依赖：

```sh
node --test docs/preview/preview-model.test.cjs
```

覆盖脚本语法、个人隔离、管理员无私有读取特权、团队只读/编辑、停用账号、同名与非法路径、父级删除、恢复冲突、递归复制、收藏、搜索、循环目录，以及动态置顶、公开/指定分享、过期撤销、收紧权限轮换 token、下载开关、分享者失权、扩展名保护和真实格式 fixture。

注意：这些是浏览器演示模型的测试，不验证服务端授权或真实并发。正式回归矩阵见 [开发方案第 15 节](shared-files-development-plan.md#15-测试与验收矩阵)。

## 手动浏览器路径

1. 林知夏 → 新建文件夹 → 进入目录 → 新建便签 → 预览。
2. 行末更多 → 重命名 → 移入回收站 → 回收站恢复。
3. 顶栏头像菜单切许清和：团队上传禁用；我的文件可上传；林知夏的私有草稿不出现。
4. 切林知夏 → 私有草稿 → 分享与权限 → 指定成员访问 → 指定许清和只读 → 保存设置；切许清和 → 与我共享 → 可预览、重命名禁用。
5. 设置 → 模拟下一份上传失败 → 我的文件上传三个测试文件 → 单项取消；其余任务独立完成/失败。
6. 失败项重试期间切换目录：任务仍写入最初捕获的目标目录；切账号，队列只显示本人任务。
7. 选择文件 → 使用平台复制/粘贴快捷键跨空间复制；也可从菜单复制，再点“粘贴已复制的文件副本”。输入框中的复制粘贴保持文本语义。
8. 列表/网格、名称搜索、排序、收藏、空结果提示均可切换。
9. 测试 1440×900、1103×771、819×771、390×844：横向无溢出；手机三个示例文件夹都可进入；导航抽屉与分享弹窗可操作。
10. 弹窗按 Esc 关闭、Tab 导航、焦点回到触发处；减少动态效果时无强制进场动画。读屏须另做人工验收。
11. 新建任意目录 → 更多 → 置顶文件夹 → 管理置顶 → 勾选/取消、上移/下移、重命名；取消后目录仍在列表。
12. 分享选择“任何人持链接访问” → 访问预览 → 访客可读取；切“指定成员访问” → 未登录/未受邀账号受限，受邀账号可读；下载关闭时按钮禁用。
13. 设置页改默认分享范围/期限/下载，新建分享面板继承默认值，不修改旧链接。
14. 账号菜单用 ArrowDown/ArrowUp、Home/End、Enter 和 Esc 操作；819px 下检查菜单与水平快捷键标签，确认不存在原生账号 select。
15. 下载示例 PDF/XLSX 与上传测试文件，核对名称/扩展名/大小/哈希；重命名只能改基本名称；ZIP 结构与 XLSX XML 可解析。
